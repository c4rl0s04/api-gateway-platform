# 📦 database

## Responsibility

The `database` package **centralizes all database access** for the API Gateway Platform. It owns:

- The **Prisma schema** defining all tables and relationships
- **Migrations** for evolving the database schema
- **Seed data** for development and testing
- The **Prisma Client singleton** shared by all other packages

> [!NOTE]
> No other package should interact with PostgreSQL directly. All database access goes through `@api-gateway/database`.

---

## Key Files

| File | Purpose |
| ---- | ------- |
| `prisma/schema.prisma` | Database schema — models, relations, enums |
| `prisma/migrations/` | Migration history (auto-generated by Prisma) |
| `src/client.ts` | Prisma Client singleton instance |
| `src/seed.ts` | Seed script for populating dev data |
| `src/index.ts` | Package entry point — re-exports client and types |
| `src/generated/` | Auto-generated Prisma Client (gitignored) |

---

## Schema Overview

The Prisma schema defines five core models:

```
Organization → Environment → ApiProxy → Endpoint → EndpointPolicy
```

Each level contains the next, forming a hierarchical configuration tree. See [[Database and Prisma]] for the full ER diagram.

---

## Scripts

| Script | Command | Purpose |
| ------ | ------- | ------- |
| `build` | `tsc` | Compile TypeScript |
| `db:generate` | `npx prisma generate` | Generate Prisma Client from schema |
| `db:migrate` | `npx prisma migrate dev` | Run pending migrations |
| `db:seed` | `npx prisma db seed` | Seed database with sample data |
| `db:reset` | `npx prisma migrate reset` | Reset DB + re-run migrations + seed |
| `db:studio` | `npx prisma studio` | Open visual database browser |

---

## Environment Variables

| Variable | Description |
| -------- | ----------- |
| `DATABASE_URL` | PostgreSQL connection string (e.g., `postgresql://user:pass@localhost:5432/gateway`) |

---

## Usage in Other Packages

```typescript
// In gateway-core or management-api:
import prisma from '@api-gateway/database';

const proxies = await prisma.apiProxy.findMany({
  include: {
    endpoints: {
      include: { policies: true }
    }
  }
});
```
